# Procrastinaut

Procrastinaut is a learning project for building a personal productivity tool for students. This repository is currently a blank scaffold; no application features or user interface have been implemented yet.

## Planned technology stack

The project is planned to use:

- HTML5 for document structure
- CSS3 for styling
- Vanilla JavaScript for application behavior
- `localStorage` for planned client-side data persistence

No frameworks, external libraries, package managers, dependencies, or build tools are planned for the initial version.

## Initial setup

1. Clone or download this repository.
2. Open the project directory.
3. Confirm that the scaffold contains `index.html`, `style.css`, `script.js`, `.gitignore`, and `README.md`.
4. Begin implementing the application manually.

## Open the project locally

Open `index.html` directly in a modern web browser. No local server or installation step is required for the current blank scaffold.

## Planned feature roadmap

The following features are planned for future development and are **not implemented yet**:

- A student productivity dashboard
- Class and course organization
- Assessment and deadline tracking
- Task and to-do management
- Break planning
- Focus sessions and timers
- Browser-based persistence using `localStorage`
- Reminders and notifications

This roadmap is documentation only. The repository currently contains no dashboard, navigation, forms, sample data, storage logic, timers, notifications, or other application functionality.
